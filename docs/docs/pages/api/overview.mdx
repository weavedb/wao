# WAO SDK

The WAO SDK extends Wander (`aoconnect`) with syntactic sugar, seamless message piping, and async message result validation to drastically reduce code size.

```bash
npm install wao
```

## Modules

| Module | Description |
|--------|-------------|
| [AO](/api/ao) | Core AO interface — spawn processes, send messages, read results |
| [Process](/api/process) | Process management and interaction |
| [Function Piping](/api/function-piping) | Chain operations with seamless message piping |
| [AR](/api/ar) | Arweave utilities — wallets, transactions, data uploads |
| [GQL](/api/gql) | GraphQL queries made easy |
| [ArMem](/api/armem) | In-memory Arweave/AO unit emulation |
| [HB](/api/hb) | HyperBEAM node management |
| [HyperBEAM](/api/hyperbeam) | HyperBEAM SDK utilities |
| [HBSig](/api/hbsig) | HyperBEAM HTTP message signatures |
