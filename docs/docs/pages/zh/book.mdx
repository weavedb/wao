# HyperBEAM 手册（预发布版）

![](/images/book.jpg)

**从零开始构建自定义设备**

本手册将教你构建自定义 HyperBEAM 设备。你将从学习 Erlang 开始，然后逐步深入代码库，从底层原语到高层设备。学完后，你将理解每个模块，并准备好创建自己的设备。

:::warning
本手册正处于早期开发阶段。内容可能不完整或随时更改，恕不另行通知。
:::

:::note[关于本手册]
针对 [HyperBEAM v0.9-milestone-3-beta-3](https://github.com/permaweb/HyperBEAM/releases/tag/v0.9-milestone-3-beta-3) 编写。每章都包含实操教程，每个模块都链接到完整的 API 参考。
:::

## 第 4 章：Arweave 工具集

Arweave 区块链原语。HyperBEAM 将所有数据存储在 Arweave 上——这些模块是基础。

:::tip
[Arweave 工具集教程](/book/ar)
:::

| 模块 | 说明 |
|--------|-------------|
| [rsa_pss](/src/rsa_pss) | 符合 RFC 3447 的 RSA-PSS 签名算法，供 ar_wallet 用于所有加密操作 |
| [ar_wallet](/src/ar_wallet) | 生成 RSA-4096 密钥对、加载 JWK 密钥文件、签名数据、验证签名、派生地址 |
| [ar_deep_hash](/src/ar_deep_hash) | 计算 Arweave 的递归 SHA-384 哈希，用于生成交易和数据项 ID |
| [ar_bundles](/src/ar_bundles) | 创建、签名、序列化和反序列化 ANS-104 数据项和捆绑包 |
| [ar_tx](/src/ar_tx) | 处理 Arweave 第一层交易，包括创建、签名和序列化 |
| [ar_timestamp](/src/ar_timestamp) | 从 Arweave 网络获取当前区块高度和时间戳，用于时间同步 |
| [ar_rate_limiter](/src/ar_rate_limiter) | 令牌桶限流器，防止请求过多压垮 Arweave 网关 |
