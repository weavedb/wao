# 快速开始

![](/images/cover.png)

## 闪电般快速的 AO 测试框架

WAO SDK 通过更优雅的语法增强与顺畅的消息管线，让 Arweave/AO 开发更轻松愉快。GraphQL 操作也变得非常简单。

## 语法糖加持的精简 AO SDK

此外，它提供了 `aoconnect` 的即插即用替代方案，通过在内存中模拟 AO 单元，使 Lua 脚本测试速度比主网快 1000 倍。相比使用 [arlocal](https://github.com/textury/arlocal) 与 [ao-localnet](https://github.com/permaweb/ao-localnet) 的测试，也能快 100 倍。

## 独立本地 AO 单元

WAO 不仅适用于内存测试，也可用于轻量级独立 AO 单元以及可嵌入 Web 的 AO 单元。只需运行命令 `npx wao`，就能在本地电脑上拥有自己的 AO 单元。

## 浏览器中的 AO

打开 [preview.wao.eco](https://preview.wao.eco) 即可在浏览器中获得完整 AO 单元（MU/SU/CU/Gateway），并配备 AOS 终端、代码编辑器和本地 AO Explorer，便于调试。

## HyperBEAM SDK

WAO 同时兼容 [HyperBEAM](https://permaweb.github.io/HyperBEAM/) 与主网 AOS 进程。你可以在 JS 测试代码中启动 HyperBEAM 节点，并为测试创建沙盒环境。

## HyperBEAM 自定义设备测试

你还可以用 Erlang、Rust 与 C++ 创建自定义 HyperBEAM 设备，并在 JS 中进行测试。
