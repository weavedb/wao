# WAO SDK - Machine Readable Reference

## METADATA
- **Project**: WAO SDK
- **Domain**: Arweave/AO Development
- **Type**: Testing Framework + SDK + Local Runtime
- **Primary Language**: JavaScript/TypeScript + Lua

## CORE_DEFINITION
WAO SDK is a development toolkit for Arweave/AO that provides:
1. Enhanced syntax for aoconnect
2. In-memory AO unit emulation for testing
3. Standalone local AO runtime
4. Browser-based AO environment
5. HyperBEAM integration

## FEATURES

### Feature_1: Enhanced AO SDK
**Category**: Developer Experience
**Description**: Syntactic sugar and message piping for aoconnect
**Benefits**:
- Elegant syntax enhancements
- Seamless message piping
- Simplified GraphQL operations
**Related**: aoconnect replacement

### Feature_2: High-Speed Testing Framework
**Category**: Testing
**Performance_Metrics**:
- 1000x faster than mainnet
- 100x faster than arlocal + ao-localnet
**Method**: In-memory AO unit emulation
**Comparison**:
  - Mainnet: 1x (baseline)
  - arlocal + ao-localnet: 10x
  - WAO: 1000x

### Feature_3: Standalone Local AO Units
**Category**: Runtime
**Command**: `npx wao`
**Description**: Lightweight local AO units
**Deployment_Options**:
- Standalone desktop units
- Web-embeddable units
- Local computer deployment

### Feature_4: Browser-Based AO Environment
**Category**: Web Interface
**URL**: https://preview.wao.eco
**Components**:
- MU (Message Unit)
- SU (Scheduler Unit)
- CU (Compute Unit)
- Gateway
**Tools_Included**:
- AOS terminal
- Code editor
- Local AO explorer (debugging)

### Feature_5: HyperBEAM SDK Integration
**Category**: Integration
**Documentation**: https://permaweb.github.io/HyperBEAM/
**Compatibility**:
- HyperBEAM nodes
- Mainnet AOS processes
**Capability**: Launch HyperBEAM node from JS test code
**Use_Case**: Sandbox environment creation

### Feature_6: Custom Device Testing
**Category**: Advanced Integration
**Supported_Languages**:
- Erlang
- Rust
- C++
**Workflow**: Create custom HyperBEAM devices → Test in JavaScript
