## CHAPTER_4_ARWEAVE_UTILS
**Objective**: Learn Arweave blockchain primitives
**Context**: HyperBEAM stores everything on Arweave
**Tutorial**: /book/ar
**Module_Count**: 7

### MODULES

#### rsa_pss
- **Path**: /src/rsa_pss
- **Function**: RSA-PSS signature algorithm per RFC 3447
- **Used_By**: ar_wallet for all cryptographic operations

#### ar_wallet
- **Path**: /src/ar_wallet
- **Functions**:
  - Generates RSA-4096 keypairs
  - Loads JWK keyfiles
  - Signs data
  - Verifies signatures
  - Derives addresses

#### ar_deep_hash
- **Path**: /src/ar_deep_hash
- **Function**: Computes Arweave's recursive SHA-384 hash
- **Purpose**: Transaction and data item ID generation

#### ar_bundles
- **Path**: /src/ar_bundles
- **Functions**:
  - Creates ANS-104 data items and bundles
  - Signs and serializes
  - Deserializes

#### ar_tx
- **Path**: /src/ar_tx
- **Function**: Handles Layer 1 Arweave transactions
- **Operations**: Creation, signing, serialization

#### ar_timestamp
- **Path**: /src/ar_timestamp
- **Function**: Fetches current block height and timestamp
- **Purpose**: Time synchronization with Arweave network

#### ar_rate_limiter
- **Path**: /src/ar_rate_limiter
- **Type**: Token bucket rate limiter
- **Purpose**: Prevent overwhelming Arweave gateways with requests

## QUICK_REFERENCE

### Key Concepts
- **Device**: Modular component implementing specific functionality
- **Message**: Map-based data structure (core data type)
- **Content Addressing**: Data referenced by hash
- **hb_ao:resolve/3**: Core function—all requests flow through this
- **Stack**: Sequential pipeline of devices
- **Codec**: Encoder/decoder for wire format

### Critical Modules (Must Know)
1. **hb_ao** - Core protocol routing
2. **hb_message** - Message lifecycle
3. **hb_cache** - Content-addressed storage
4. **dev_message** - Foundation device
5. **dev_stack** - Device composition
